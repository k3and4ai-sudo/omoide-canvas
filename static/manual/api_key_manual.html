第1部：Google アカウントの作成手順

※すでにGoogleアカウントをお持ちの方は2ページ目へ
手順 1-1
Googleのログイン画面から「アカウントを作成」を選ぶ

スマホまたはパソコンのブラウザ（Safari / Chrome）で下のアドレスを開きます。

https://accounts.google.com/signup
  1. 画面下部の 1「アカウントを作成」 をタップします。
  2. 表示されたメニューから 2「個人で使用」 を選択します。

第2部：Gemini APIキーの作成手順（Google AI Studio）

※無料で即座に発行できます（クレジットカード不要）
手順 2-1
Google AI Studio を開いて利用規約に同意する

以下の公式ページを開くか、おもいでキャンバスのログイン画面下部のリンクをタップします。

https://aistudio.google.com/app/apikey
  1. Googleアカウントでログインします。
  2. 初回のみ表示される画面で 1利用規約のチェックボックス にチェックを入れ、2「Continue（続行）」 を押します。
🔒 aistudio.google.com/app/apikey
✦ Welcome to Google AI Studio
1 ☑️ I accept the Additional Terms of Service and acknowledge the Privacy Notice.
Continue（続行） 2
手順 2-2
「Create API key（APIキーを作成）」を押してキーをコピーする
  1. 左上の 1「Get API key」（または画面右上の青い 「＋ Create API key」 ボタン）をタップします。
  2. 「Create API key in new project（新しいプロジェクトでAPIキーを作成）」 を選びます。
  3. AIzaSy... で始まる文字列が表示されたら、2「Copy（コピー）」 ボタンを押します。

第3部：「おもいでキャンバス」へのログイン手順

※次回からは自動入力されます
手順 3-1
起動時のログイン画面にAPIキーを貼り付けて開始する

スマホやPCで「おもいでキャンバス」の公開アドレスを開きます。

https://k3and4ai-sudo.github.io/omoide-canvas/
  1. 起動時に表示されるログイン画面の 1「Gemini API キー」入力欄 に、先ほどコピーしたキー（AIzaSy...）を貼り付けます。
  2. 2「この端末のブラウザにのみ記憶する」 にチェックを入れておくと、次回から入力不要になります。
  3. 3「🚀 このAPIキーでログインして開始」 をタップすると認証が完了し、すぐにお話を始められます！
